# SQL Server Learning Path (Database Learning — Phase 1)

An 80/20, hands-on, scenario-driven path through SQL Server / T-SQL for a full-stack Angular + .NET developer. MongoDB (Phase 2) is gated behind joins, window functions, indexing and transactions.

| Folder | Contents |
|---|---|
| `Roadmap/` | `SQL_Server_Roadmap` (.md + .pdf): modules M0–M12, 🔴/🟡/⚪ tags, RetailOrderDb schema, the Phase 2 gate |
| `Prompts/` | `Database_Master_Prompts`: Gen / Lab / Review / Drill / Consolidate / Module PDF triggers |
| `Labs/setup/` | `01_schema.sql`, `02_seed.sql` for RetailOrderDb (written in M1) |
| `Labs/Mxx/` | Your solutions to each module's scenario tickets |
| `Modules/Mxx/` | Consolidated topic notes (.md) |
| `PDFs/` | One reference PDF per module |

Per-module loop: `Gen:` topics → labs in SSMS → `Lab: Mx` tickets → `Review:` → `Drill: Mx` → `Consolidate:` → `Module PDF: Mx` → commit.

The previous roadmap is kept in `../SQL_Learning_Path_AI-main/` for history.
