Core Framework
Term
Analogy
Technical Definition
Angular
The building's architecture blueprint
Frontend framework by Google for building SPAs
Component
A room in the building
UI building block — class + template + styles
Template
The room's interior design
HTML with Angular syntax bound to the component class
Service
Building plumbing — shared, runs behind walls
Injectable singleton class for shared logic/data
Dependency Injection
Calling reception instead of building it yourself
Design pattern — Angular provides class instances via inject()
Standalone
A room that brings its own furniture
Component that declares its own imports, no NgModule needed
Module (legacy)
A floor grouping related rooms
NgModule — legacy grouping mechanism for components/services
Decorator
A name badge clipped onto a class
TypeScript metadata annotation — e.g. @Component, @Injectable
Input / Output
Room door slot — data in, events out
Component API — input() passes data down, output() emits events up
Lifecycle Hook
Room alarm at key moments — entering, settling, leaving
Interface methods Angular calls at defined points in a component's life

Analogy
Technical Definition

Change Detection
