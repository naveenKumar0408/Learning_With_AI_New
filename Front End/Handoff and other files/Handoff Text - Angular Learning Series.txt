### QUICK REFERENCE SUMMARY (all completed topics)

**Topic 1 — `let`/`const`/`var`**
> Default to `const`, `let` when reassigning, `var` never.
- `const` = locked box | `let` = open box | `var` = everyone's box

**Topic 2 — Block Scope & Hoisting**
> Hoisting = HR paperwork before day one. `var` = building pass.
`let`/`const` = room pass with locked door until declaration line.
- TDZ = badge created but not activated

**Topic 3 — Closures & Lexical Scope**
> A closure is a backpack — packed at birth, opened when it runs.
- Capture variables not values — live TV feed not a photo
- Always unsubscribe — take down your tent

**Topic 4 — Arrow Functions & `this`**
> Regular function = temp worker no ID. Arrow = permanent employee
name tag always on.
- Arrow callbacks always safe in Angular async code
- Arrow class properties for methods passed as references

**Topic 5 — The Event Loop**
> One waiter, one task. Kitchen handles long orders. Pickup counter
checked only when waiter is free.
- Call Stack → Web APIs → Queue → Microtask queue runs first

**Topic 6 — Callback Functions**
> Instructions handed to someone else to run when ready.
- Sync callbacks = array methods (immediate)
- Async callbacks = HTTP/timers (from queue)
- Never nest beyond 2 levels — use RxJS to flatten

**Topic 7 — Pass by Value vs Reference**
> Primitives = photocopy. Objects = house key. OnPush = security
guard checking keys not furniture.
- Mutation invisible to OnPush — always return new references

**Topic 8 — Promises & async/await**
> Promise = buzzer. `await` = wait without freezing. `Promise.all`
= all contractors at once.
- Always try/catch. Observables for streams, async/await for
one-time ops.

**Topic 9 — Array Methods**
> `map` = transform all. `filter` = keep some. `reduce` = snowball.
`find` = spotlight. `forEach` = look don't touch.
- Filter before map. `sort` mutates — spread first.

**Topic 10 — Destructuring & Spread**
> Unpack the suitcase. Photocopy to new location. Collect leftovers.
Spread is always shallow. Later spread wins.
- Spread each nested level that changes

**Topic 11 — Template Literals**
> Mad Libs for strings. Backticks frame, `${}` fills the blanks.
Multi-line free. `.trim()` keeps it clean.
- `encodeURIComponent()` for user input in URLs

**Topic 12 — Modules & Imports/Exports**
> Every file is a private LEGO set. `export` shares. `import`
borrows. Barrel files are the index page.
- Named exports always. `CommonModule` for `*ngFor`/`*ngIf`.
- Standalone components preferred for new Angular apps.

**Topic 13 — TypeScript Interfaces & Types**
> Interfaces = blueprints. Compile-time only — disappear at runtime.
`any` = hole in the dam.
- `Partial`, `Omit`, `Pick` build new blueprints from old ones
- Optional chaining + Zod for runtime safety
