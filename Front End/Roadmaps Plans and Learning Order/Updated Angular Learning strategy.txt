Learning Strategy
One topic = one session = one small working piece of an app.
Every topic you learn, you write code that runs. Not a full app — just the relevant slice. By the end of the roadmap, those slices connect into something real.
No printing mid-way. Learn → build a small piece → note it for print later.

Session Format (Apply Every Time)

Ask me to explain the topic — I'll cover the why, what, and how
You build a small piece — I give you a starter prompt
You paste what you built — I review and flag any anti-patterns
Note it for print — once it's solid
