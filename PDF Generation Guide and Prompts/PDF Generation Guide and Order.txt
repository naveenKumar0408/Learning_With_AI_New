Three important things to do in EVERY chat before pasting the prompt:
Thing 1 — Say this first line before the prompt:

"Do not start until I say GO. Read this entire instruction first."

Then paste the prompt. Then say GO.
This prevents Claude from starting before it has read all the instructions.
Thing 2 — If the PDF build gets cut off mid-way:
Say exactly this:

"The build was cut off. Continue from where you stopped. Do not rebuild what is already done. Merge the completed parts and the remaining parts into one final PDF."

Thing 3 — After the PDF is downloaded, verify it:
Scroll to the last page and check the last topic is there. Scroll to the middle and spot-check one section. If anything is missing say:

"Topic X is missing from the PDF. Add it and regenerate."


After all PDFs are generated — the merge step:
Once you have all individual PDFs downloaded, start one final new chat and say:

"I need to merge multiple PDFs into one master document. I will upload them one by one. Merge them in the order I upload them. Do not alter any content. Just merge and output one combined PDF."

Then upload each PDF in the correct topic order. This gives you one complete 59-topic reference document for printing.

Token conservation tip:
The simple plain text PDF uses roughly 20–30% of the tokens that the styled Head First version used. Each chat should be able to generate its PDF in one session without hitting limits. If a chat is already near its limit from the original conversation, the build may still get tight — in that case the "continue from where you stopped" instruction above handles it.
